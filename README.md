Ozark Roost — Monetization scaffold

This repository now contains a minimal static site scaffold to begin collecting affiliate revenue and capture leads.

Next steps (configure before deployment):
- Replace MEASUREMENT_ID in index.html with your Google Analytics 4 measurement ID.
- Replace affiliate link placeholders (data-affiliate / href) with your affiliate URLs from Amazon, ShareASale, Awin, etc. Add rel="sponsored".
- Configure the subscribe form action: replace /subscribe with your Mailchimp/ConvertKit endpoint or use Netlify Forms.
- Deploy to Netlify/Netlify Drop, Vercel, or GitHub Pages; enable HTTPS.
- Add conversion tracking and verify with GA/Tag Assistant.
