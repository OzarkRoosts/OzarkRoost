# OzarkRoost Growth Engine

## Traffic system

1. **Crawler:** `npm run seo:crawl` audits sitemap URLs for HTTP failures, titles, descriptions, canonical URLs, H1 count, and internal-link discovery. It is bounded to 250 pages and stays on the canonical OzarkRoost host.
2. **SEO:** expand useful destination and adventure clusters from real Ozarks travel intent. Do not mass-produce thin pages or doorway pages. Google explicitly treats scaled low-value content and doorway abuse as spam. 
3. **Funnel:** discovery page → useful guide/adventure → stay/adventure action → tracked affiliate/outbound action → operator listing CTA. Operator pricing is now aligned to the live $99/$149/$199 tiers.
4. **Social:** use Metricool for scheduled organic distribution across connected networks. Every post should point to a specific useful page rather than repeatedly sending traffic to the homepage.
5. **Free promotion:** prioritize organic social, Google Business Profile posts when connected, partner/referral links, community participation where self-promotion is permitted, and shareable guides. No automated spam, fake accounts, mass comments, or scraped-content posting.
6. **Measurement:** track landing-page sessions, outbound affiliate clicks, operator inquiries, listing checkout starts, and completed Stripe sessions separately. Render request counts are not unique visitors.

## Campaign themes

- Buffalo River trip planning
- Eureka Springs weekend
- Ozarks waterfalls
- Cabins with hot tubs / pet-friendly stays
- Fishing and floating
- Scenic drives
- Mountain biking / Bentonville
- Fall and spring trip guides
- "Build your trip" itinerary content
- Operator acquisition: list a cabin/campground/RV park

## Social CTA rule

Use one primary CTA per post:
- Plan a trip → a guide/destination page
- Find an adventure → an adventure page
- Find a stay → listings
- List a property → /list-your-cabin

All campaign links should use the canonical `https://ozarkroost-jibz.onrender.com` host.
